# Hospital Management System

## Overview

The Hospital Management System is a Python and SQLite application developed as a portfolio project to demonstrate object-oriented programming, relational database design, CRUD operations, data validation, and business rule implementation.

The system is designed to manage hospital information including patients, consultants, GP surgeries, departments, appointments, medications, prescriptions, and billing.
